# Contributing

Thanks for your interest in improving this agent.

1. Open an issue first to describe the bug or idea.
2. Fork the repository and create a branch for your change.
3. Keep every example and fixture synthetic. Never add real personal, institutional or research data.
4. Run the bundled tests or scripts described in the README before opening a pull request.
5. Describe what changed and why in the pull request.

Pull requests that keep the agent's evidence-first, no-invented-facts rules intact are the easiest to merge.
