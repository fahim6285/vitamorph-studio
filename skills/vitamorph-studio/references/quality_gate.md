# Quality gate: complete before delivery

## Content integrity
- [ ] Single master document and snapshot date identified.
- [ ] Every numerical claim supported by a reliable source and recorded in internal claims ledger.
- [ ] Total publications equal category sum OR discrepancy resolved, without hidden category changes.
- [ ] All requested entries present; no arbitrary truncation (check number of rows in every section).
- [ ] Duplicate DOIs/normalized titles reviewed; correct DOI URL spelling.
- [ ] Institution: current vs historical accurately distinguished.
- [ ] Grant PI / Co-PI role, project amount, date, funder checked.
- [ ] Academic degrees, patents, guidance, service roles, ranking year checked.
- [ ] Scopus, Google Scholar, WoS numbers separately attributed and date stamped.
- [ ] No fabricated missing bibliographic details or claims.

## Professional CV
- [ ] Clear headings, page breaks, consistent dates, correct numbering.
- [ ] Fonts/alignment/tables consistent, no awkward text clipping.
- [ ] Full CV vs short CV clearly distinguished.
- [ ] No 'supplied/generated/as per sheet' source notes in publishable document.
- [ ] Complete publication list when requested.

## Public website
- [ ] Content matches the approved CV exactly, including metrics, current affiliation, role wording.
- [ ] Only approved public profile fields and links included; no private email, phone, home address, student IDs.
- [ ] No internal review/audit files in website ZIP.
- [ ] Search, category filtering, sorting, navigation, print and share/copy work.
- [ ] Responsive at narrow/mobile and desktop widths; keyboard focus visible.
- [ ] Page title, meta description, canonical/OG if actual URL exists.
- [ ] High-contrast, restrained visual theme; site owner approves palette.
- [ ] Empty categories degrade gracefully; zero statistics are not invented.
- [ ] Website does not claim to be deployed until the service verifies deployment.

## Delivery
- [ ] DOCX/PDF files opened or conversion tested if generated.
- [ ] Website `index.html` opens and all local assets exist.
- [ ] Static profile verifier passes; uncertain entries called out externally.
- [ ] ZIP opens and has expected structure.
- [ ] Exact artifact links point to existing files.
