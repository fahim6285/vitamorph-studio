# Security and privacy

This repository contains agent instructions, templates and small offline Python scripts. It contains no credentials and no real personal or institutional data.

If you find a security problem or accidentally committed private data, please open a GitHub issue that describes the location without repeating the sensitive content, or use GitHub's private "Report a vulnerability" option in the Security tab.

When using the agent, never paste passwords, API keys, government IDs or other secrets into prompts.
