# Sample prompts for VitaMorph Studio

Copy any prompt, attach your own source files and adjust the details.

1. Follow VitaMorph Studio to audit my CV and list every claim that has no source.
2. Turn my approved CV into an interactive personal academic website I can host on Netlify.
3. Compare my two CV versions and show every discrepancy in dates, titles and counts.
4. Restructure my CV for a faculty application and keep every claim traceable to a source.
5. Prepare a one-page professional bio that matches my CV exactly.
6. Run the public-site privacy checks and tell me what must be fixed before I publish.

Tip: attach the official source (posting, syllabus, methodology or CV) and say the exact output format you want. The agent works best when it can cite what you provided.
